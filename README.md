# breakfast

00 專屬早餐清單：<https://kate96482.github.io/breakfast/>

- 吐司機抽籤幫忙決定今天吃哪家，會避開打烊的、最近吃過的
- 滑動卡片／看全部 兩種檢視，可依類型篩選，營業中的排前面
- 自動／白天／夜間三種模式，4 套主題皮膚，荷包蛋夥伴依時間打招呼
- 吐司機、扭蛋機兩種抽籤動畫，可以搖手機抽籤
- 14:00 之後自動抽「明天早餐」（排除明天公休），可以記住，隔天早上提醒
- 我的早餐：今日運勢、早餐週曆、早餐護照
- 管理模式可以直接在網頁上新增、修改、刪除店家，資料存在 Google 試算表

設定方式見 [docs/部署說明.md](docs/部署說明.md)。
